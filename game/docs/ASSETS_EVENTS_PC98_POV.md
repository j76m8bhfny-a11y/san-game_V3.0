---

## 🎨 Prompt Philosophy

### Problem with Previous Prompts
❌ `wide angle establishing shot` → Generated crowds walking  
❌ `panoramic scene view` → Lost focus on specific event  
❌ `diverse Americans crowd` → Background pedestrians dominated  

### Solution: First-Person/POV Focus
✅ `first-person view` / `over-the-shoulder` / `close-up of hands`  
✅ `solitary figure` / `intimate close-up`  
✅ `no crowd, no background pedestrians`  
✅ Specific moment, specific action

---

## 📐 Standard Template

```
PC-98 style, retro adventure game scene, pixel art, 1990s anime style,
16-bit color palette, dithering patterns, scanline effect,
3:2 aspect ratio (960x640),
[Specific US location],
[First-person POV or over-the-shoulder perspective],
[Focused detail on event subject],
[Atmosphere mood],
solitary figure or intimate close-up,
no crowd, no background pedestrians,
no signs, no text, no labels, no placards
```

### Keywords That Create Crowds (REMOVE)
- `wide angle` → Too much background
- `panoramic` → Crowds appear
- `establishing shot` → General scene
- `diverse crowd` → Background people
- `full scene` → Lacks focus

### Keywords That Focus (USE)
- `first-person view` / `POV` → Subject's perspective
- `over-the-shoulder` → Behind main character
- `close-up of hands` → Action detail
- `solitary figure` → Single person
- `intimate close-up` → Personal moment
- `no crowd, no background pedestrians` → Negative prompt
