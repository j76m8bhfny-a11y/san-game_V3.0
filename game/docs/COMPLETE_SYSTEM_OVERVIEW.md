## 一、核心世界观公式

```
S = σ(HP↓, M↓, Insight↑)

其中:
- HP (生命值): 肉体的存续
- M (精神稳定): 社会的融入度  
- Insight (灵视): "痛苦的清醒" —— 越高越看清真相，也越痛苦

生存率 S 与 Insight 负相关:
- Insight ≤ 20: 蒙昧的幸福 (ED-21)
- Insight 70-84: 觉醒者 (ED-22)
- Insight ≥ 85: 真结局 (ED-20, ED-22)
- Insight 95 但无知识: 阿卡姆病栋 (ED-10)
```

**核心设计**: 
> "看清真相不会让你自由，只会让你更痛苦。但如果你收集足够的知识（档案），你可以选择烧毁整个系统。"

## 三、核心系统详解

### 3.1 生存系统 (Vitality System)

**文件**: `createVitalitySlice.ts`

#### 核心指标

| 指标 | 范围 | 说明 |
|------|------|------|
| `hp` | 0-100 | 生命值，归零即死亡 |
| `insight` | 0-100 | 灵视值，"痛苦的清醒" |
| `gold` | -∞ ~ +∞ | 金钱，可为负（负债）|
| `creditScore` | 300-850 | 信用评分 |
| `addiction` | 0-100 | 成瘾度 |
| `hunger` | 0-100 | 饥饿度 |

#### 每周自动消耗

```typescript
// 基础衰减
HP -= 2 ~ 8 (取决于饮食、住房)
Hunger += 10

// 高灵视惩罚
if (Insight > 70) {
  HP -= (Insight - 70) * 0.1;  // 看透真相让人虚弱
}
```

#### 与其他系统的耦合
- **住房系统**: 住房质量影响 HP 回复
- **饮食系统**: 垃圾食品增加成瘾度
- **医疗系统**: 疾病降低 HP
- **结局系统**: HP≤0 触发死亡结局

### 3.4 加密货币系统 (Crypto System)

**文件**: `createCryptoSlice.ts`, `market.ts`, `market_rules.json`

#### 核心设计: "中产财富毁灭机"

```
初始价格: $69,000 (历史高点)

费用结构:
- 开户费: $0 (免费诱入)
- 网络费: $50 + 2%本金 (小交易不划算)

- 50x+杠杆有60%概率遭遇"插针"(flash crash)
- 瞬间 -80% 价格 → 强制平仓
- 爆仓触发 ED-05 天台结局

Insight 耦合:
- 持有仓位每周 +5 Insight (盯盘精神内耗)
- 爆仓瞬间 +30 Insight (财富归零的顿悟)
```

#### 爆仓→自杀结局联动
```typescript

if (liquidation) {
  deathReason = 'SUICIDE';
  endingId = resolveEnding(state, endings, 52, 'SUICIDE');
  // ED-05 天台的抛物线
```

### 3.7 医疗系统 (Medical System)

**文件**: `createMedicalSlice.ts`, `hospital_services.json`

#### 核心机制: "美国医保陷阱"

```
诊疗流程:
1. 挂号费 (当场支付)
2. 诊疗服务 (延迟账单)
3. 保险报销 (部分)

延迟账单 (达摩克利斯之剑):
- 治疗时: 只付挂号费
- 2-4周后: 收到巨额账单

```

#### 服务类型

| 类型 | 说明 | 风险 |

| SURGERY | 手术 | 高费用、排期 |
| THERAPY | 心理治疗 | 降低 Insight |
| SPECIAL | 特殊服务 | 卖器官 |
| EMERGENCY | 急诊 | 最贵、保险可能不包 |

```typescript
// nextTurn() 调用顺序

   - EventSystem.processTurn()
   - BillSystem.processTurn()

```

```typescript
// resolveEnding 调用点

sortedEndings.sort((a,b) => b.priority - a.priority)
```

## 九、总结

《美式灵视》是一个**系统高度耦合、叙事深度嵌入机制**的生存游戏。

### 核心体验循环

```
玩家进入系统 → 尝试生存 → 遭遇陷阱 → 负债/受伤 →
```
