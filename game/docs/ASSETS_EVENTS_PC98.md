> 版本: 1.0 | 按阶级分类 | 可复用背景与前景素材

---

## 🎨 风格规范

### 核心风格关键词
```
PC-98 style, retro adventure game background, pixel art, 1990s anime style,
16-bit color palette, dithering patterns, scanline effect,
complete full view, no truncation, isolated elements
```

### 技术要求
| 属性 | 规格 |
|------|------|
| **背景分辨率** | 640x480 (标准场景) |
| **前景分辨率** | 320x240 ~ 640x480 (根据内容) |
| **色彩** | 16-bit，256色限制，dithering |
| **透明背景** | 前景图需要alpha通道 |
| **完整性** | 所有人物/物品必须完整显示，不能截断 |
| **构图** | 背景无UI元素、无对话框、无文字 |
