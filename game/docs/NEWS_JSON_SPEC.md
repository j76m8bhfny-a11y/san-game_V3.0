# 加密货币市场新闻配置文档 (news.json)

> **用途**: 定义比特币市场每周随机新闻事件，驱动价格波动和玩家决策  
> **目标读者**: 内容策划/文案（负责生成新闻文本）  
> **文件位置**: `src/assets/data/news.json`  
> **耦合系统**: 加密货币市场 (`market.ts`)、价格算法 (`calculateNextPrice`)

---

## 一、核心设计原则

### 1.1 新闻的叙事定位

加密货币新闻是**"中产阶级的信息陷阱"**:
- 看似专业的财经资讯，实则是精心设计的误导
- 利好新闻往往伴随暴跌，利空消息可能是反向指标
- 反映了真实加密市场的"割韭菜"本质：信息不对称

### 1.2 效果值设计哲学

| 效果范围 | 市场反应 | 玩家心理 | 使用场景 |
|---------|---------|---------|---------|
| +15%~+10% | 明显利好 | FOMO（害怕错过）| 诱多陷阱 |
| +5%~+2% | 温和利好 | 放松警惕 | 温水煮青蛙 |
| -1%~+1% | 噪音 | 困惑/无聊 | 市场迷茫期 |
| -5%~-2% | 温和利空 | 轻微焦虑 | 正常回调 |
| -20%~-12% | 明显利空 | 恐慌 | 黑天鹅事件 |
| -30% | 极端利空 | 绝望 | 交易所跑路前兆 |

## 二、JSON 结构规范

### 2.1 基础字段

```json
{
  "id": "NEWS_XXX_序号",           // 唯一标识符，格式: NEWS_[类型]_[序号]
  "text": "新闻文本内容",           // 显示在滚动条和弹窗中的文本
  "effect": 0.15                   // 价格影响系数 (-0.5 ~ +0.5)
}
```

### 2.2 可选字段（陷阱新闻）

```json
{
  "id": "NEWS_TRAP_XX",
  "text": "...",
  "effect": -0.15,
  "trap": true,                     // 标记为陷阱新闻（利好出尽/诱多）
  "flavor": "内部说明：这是诱多陷阱"  // 仅供策划参考，不显示给玩家
}
```

### 2.3 字段详细说明

| 字段 | 类型 | 必填 | 说明 | 示例 |
|-----|------|-----|------|------|
| `id` | string | ✅ | 唯一标识，建议格式 `NEWS_[BULL/BEAR/TRAP/NOISE]_序号` | `NEWS_TRAP_01` |
| `text` | string | ✅ | 新闻文本，需要 `>>> ... <<<` 包裹增强仪式感 | `>>> 重磅: SEC批准ETF! <<<` |
| `effect` | number | ✅ | 对下周价格的影响百分比（小数形式） | `0.15` = +15% |
| `trap` | boolean | ❌ | 标记为"陷阱新闻"，实际效果与表面相反 | `true` |
| `flavor` | string | ❌ | 内部备注，解释设计意图 | `"利好出尽就是利空"` |

## 三、新闻类型与配比

### 3.1 四大类型

```
BULL (牛市新闻)    - 表面利好，效果为正
BEAR (熊市新闻)    - 表面利空，效果为负  
TRAP (陷阱新闻)    - 表面利好，实际利空（或反之）
NOISE (噪音新闻)   - 效果微弱，迷惑性强
```

### 3.2 推荐配比

| 类型 | 占比 | 数量(10条为例) | 作用 |
|-----|------|---------------|------|
| BULL | 20% | 2条 | 给玩家希望 |
| BEAR | 30% | 3条 | 制造恐惧 |
| **TRAP** | **30%** | **3条** | **核心收割工具** |
| NOISE | 20% | 2条 | 降低玩家信任 |

### 3.3 陷阱新闻设计要点

**陷阱新闻是系统的精髓**，必须满足：

1. **文本极具煽动性**
   - 使用"重磅"、"官方"、"机构"等权威词汇
   - 制造"错过这班车就永远错过"的紧迫感

2. **效果与文本强烈反差**
   - 文本: "SEC批准ETF！机构资金涌入！"
   - 实际: `-0.15` (暴跌15%，利好出尽)

3. **现实隐喻**
   - 每条陷阱新闻都应映射真实加密市场的经典骗局
   - 如ETF批准、央行降息、巨鲸入场等

## 四、文案风格指南

### 4.1 格式规范

```
>>> 标签: 新闻内容 <<<
```

- 使用 `>>>` 和 `<<<` 包裹，营造滚动新闻条的机械感
- 标签建议: `快讯`/`政策`/`警告`/`监管`/`重磅`/`链上数据`
- 总长度控制在 50-80 字符（适配UI显示）

### 4.2 语气与叙事

**要体现的主题**: "专业包装的骗局"

- ✅ **使用**: 财经术语、数据、权威机构名
- ✅ **使用**: 感叹号、省略号制造紧迫感
- ❌ **避免**: 直白说"比特币涨了/跌了"
- ❌ **避免**: 过于夸张的修辞（保持"专业"假象）

### 4.3 示例对比

| 普通写法 | 优化后（符合风格） |
|---------|------------------|
| "比特币价格将上涨15%" | ">>> 快讯: 全球最大对冲基金宣布配置5%比特币资产 <<<" |
| "市场要崩盘了" | ">>> 警告: 某大型交易所暂停提币，传闻遭受黑客攻击 <<<" |
| "有鲸鱼在卖币" | ">>> 链上数据: 某巨鲸地址苏醒，将50,000 BTC转入交易所钱包 <<<" |

## 五、现有配置参考

### 5.1 标准新闻（7条）

```json
// 明显利好
{ "id": "NEWS_BULL_01", "text": ">>> 快讯: 全球最大对冲基金宣布配置 5% 比特币资产 <<<", "effect": 0.15 }
{ "id": "NEWS_BULL_02", "text": ">>> 政策: 某岛国宣布比特币为法定货币，游客数量激增 <<<", "effect": 0.10 }

// 明显利空  
{ "id": "NEWS_BEAR_01", "text": ">>> 警告: 某大型交易所暂停提币，传闻遭受黑客攻击 <<<", "effect": -0.20 }
{ "id": "NEWS_BEAR_02", "text": ">>> 监管: 联邦税务局要求所有加密交易实名申报，引发恐慌抛售 <<<", "effect": -0.12 }

// 噪音（弱效果）
{ "id": "NEWS_NOISE_01", "text": ">>> 趣闻: 有人花费 10,000 BTC 购买了两块披萨 <<<", "effect": 0.0 }
{ "id": "NEWS_NOISE_02", "text": ">>> 科技: 新型量子计算机原型机问世，但在挖矿方面表现平平 <<<", "effect": 0.02 }
{ "id": "NEWS_NOISE_03", "text": ">>> 社区: 狗狗币表情包 NFT 拍出天价，与 BTC 走势无关 <<<", "effect": -0.01 }
```

### 5.2 陷阱新闻（3条，核心）

```json
// 诱多陷阱1: ETF批准（经典"利好出尽"）
{
  "id": "NEWS_TRAP_01",
  "text": ">>> 重磅: SEC正式批准首个比特币现货ETF！机构资金即将涌入！ <<<",
  "effect": -0.15,
  "trap": true,
  "flavor": "利好出尽就是利空，大户砸盘收割"
}

// 诱多陷阱2: 降息预期（流动性陷阱）
{
  "id": "NEWS_TRAP_02", 
  "text": ">>> 宏观: 美联储主席暗示即将降息，流动性宽松预期引爆加密市场！ <<<",
  "effect": 0.02,
  "trap": true,

}

// 诱空陷阱3: 巨鲸转币（假摔真拉或真砸盘）
{
  "id": "NEWS_TRAP_03",
  "text": ">>> 链上数据: 某巨鲸地址苏醒，将50,000 BTC转入交易所钱包！ <<<",
  "effect": -0.30,
  "trap": true,
  "flavor": "准备砸盘的明确信号，但空头也可能被反向插针爆仓"
}
```

## 六、生成工作流程

### 6.1 需求分析

在生成新闻前，明确这条新闻的**设计目的**：

```
- 这条新闻想让玩家做什么？（开多/开空/观望）
- 玩家相信这条新闻后会有什么后果？
- 是否符合"中产陷阱"的主题？
```

### 6.2 撰写模板

```markdown
### 新闻条目模板

ID: NEWS_[类型]_XX
类型: [BULL/BEAR/TRAP/NOISE]

文本草案:
>>> [标签]: [具体内容] <<<

效果值: [0.XX / -0.XX]

设计意图:
- 玩家看到后会: [预期玩家行为]
- 实际结果是: [实际市场反应]
- 现实映射: [对应真实事件]

[如果是TRAP]
陷阱说明: [为什么这是陷阱，玩家如何被割]
```

### 6.3 审核清单

提交前检查：

- [ ] ID 格式正确且不重复
- [ ] 文本使用了 `>>>` `<<<` 包裹
- [ ] effect 值在合理范围 (-0.5 ~ +0.5)
- [ ] TRAP 新闻有 `trap: true` 标记
- [ ] 文本长度适中（50-80字符）
- [ ] 符合游戏世界观（美国底层/中产困境）

### 6.4 提交流程

```
1. 本地编辑 news.json（使用 JSON 验证工具检查格式）
2. 在测试环境中验证效果
   - 触发新闻，观察价格变化是否符合预期
   - 检查 UI 显示是否正常（文本截断问题）
3. 提交 PR 并标注 "内容: 加密新闻"
4. 策划审核叙事一致性
5. 数值审核效果平衡性
6. 合并到主分支
```

## 七、进阶技巧

### 7.1 叙事弧光设计

建议按"赛季"设计新闻组：

**赛季1: 牛市狂热期**（5-6条，多为BULL+TRAP）
- 营造"再不入场就晚了"的氛围
- 配合初始高价($69,000)，玩家高位接盘

**赛季2: 市场震荡期**（3-4条，NOISE为主）
- 价格波动微弱，手续费慢慢吞噬本金
- 玩家陷入"再等等看"的观望

**赛季3: 黑天鹅崩盘期**（2-3条，BEAR+极端TRAP）
- 交易所跑路、监管重锤
- 完成财富清零

### 7.2 与现实事件联动

可基于真实加密货币历史事件改编：

| 真实事件 | 改编方向 | 效果值 |
|---------|---------|--------|
| 2021年萨尔瓦多BTC法币化 | NEWS_BULL_02 | +10% |
| 2022年LUNA崩盘 | 可新增NEWS_TRAP_04 | -80%（极端） |
| 2022年FTX倒闭 | NEWS_BEAR_03 或 B_CRYPTO_EXCHANGE_HACK账单 | -40% |
| ETF通过后的"卖事实" | NEWS_TRAP_01 | -15% |

## 八、QA 常见问题

**Q: effect 0.15 是什么意思？**
> A: 表示下周比特币价格将上涨 15%。算法: `nextPrice = currentPrice * (1 + 0.15)`

**Q: 为什么 TRAP 新闻的 effect 和文本相反？**
> A: 这是设计意图。文本制造看涨假象吸引玩家做多，实际负效果导致价格下跌，完成"割韭菜"。

**Q: 一条新闻可以多次触发吗？**
> A: 可以，新闻池是随机抽取的，同一条新闻可能在多个周期重复出现。

**Q: 如何测试新闻效果？**
> A: 在浏览器控制台模拟:
> ```javascript
> import { calculateNextPrice } from '@/logic/market';
> calculateNextPrice(69000, 0.15); // 测试+15%效果
> ```

**Q: 新闻太多会不会让玩家困惑？**
> A: 这是设计意图。真实加密市场就是信息过载、真假难辨。玩家的困惑正是"中产陷阱"的体验。
