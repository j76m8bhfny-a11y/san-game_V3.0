# Event Assets Guide - PC-98 Event-Focused

> Version: 6.0 | Event-Centric Scenes | 3:2 (960x640) | 250 Events

## 🎯 核心理念

**不再说"在哪里"，而是说"看到什么事件"**

### 错误示例 ❌
- "bathroom line" → 生成排队的人群
- "park scene" → 生成普通公园
- "pharmacy counter" → 生成普通药房

### 正确示例 ✅
- "plastic bottle filled with urine hidden beside workstation" → 尿瓶事件本身
- "metal anti-homeless dividers installed between bench slats" → 尖刺本身
- "insulin vial with price tag showing $330" → 价格困境本身
