## 🎵 一、背景音乐 BGM（优先级：高）

### 1.1 bgm_title.mp3 - 标题界面
- **时长**: 2-3分钟循环
- **情绪**: 神秘、压抑、不安
- **参考风格**: 
  - 《银翼杀手2049》原声带
  - 《机械姬》配乐
  - 暗黑氛围电子
- **乐器建议**: 合成器drone、低音贝斯、电子打击乐
- **BPM**: 60-70（缓慢）

### 1.2 bgm_blue_pill.mp3 - 蓝药丸（日常阶段）
- **时长**: 3-4分钟循环
- **情绪**: 日常、平淡、隐约不安
- **参考风格**:
  - 办公室/电梯背景音乐
  - 低保真(Lofi)但带有微妙的不和谐音
  - 《模拟人生》风格但有扭曲
- **乐器建议**: 轻柔钢琴、合成器pad、轻微失真的弦乐
- **BPM**: 80-90（中慢）

### 1.3 bgm_cracks.mp3 - 裂痕（觉醒阶段）
- **时长**: 3-4分钟循环
- **情绪**: 紧张、觉醒、系统故障感
- **参考风格**:
  - 《网络谜踪》配乐
  - 故障艺术(Glitch)音乐
  - 工业电子
- **乐器建议**: 故障音效、失真合成器、不规则节拍、金属敲击
- **BPM**: 100-120（中快）
- **特殊效果**: 模拟音频故障、跳帧、静电噪音

### 1.4 bgm_old_ruler.mp3 - 古神（高Insight阶段）
- **时长**: 3-4分钟循环
- **情绪**: 宇宙恐惧、古老、超越理解
- **参考风格**:
  - 《真探》第一季配乐
  - 克苏鲁风格氛围音乐
  - 仪式性合唱
- **乐器建议**: 低沉吟唱、管风琴、钟铃、反向音效
- **BPM**: 50-60（极慢）
- **特殊效果**: 不可名状的低频震动、仿佛来自远古的回声

## 🎚️ 六、技术规格

### 音频格式
- **格式**: MP3 (主要), OGG (备选)
- **采样率**: 44.1kHz
- **比特率**: 
  - BGM: 192-320kbps
  - SFX: 128-192kbps
- **声道**: 立体声 (BGM), 单声道 (SFX)

### 命名规范
- 使用小写字母
- 单词间用下划线 `_` 连接
- BGM前缀: `bgm_`
- 音效前缀: `sfx_`
- 环境音前缀: `amb_`

### 文件大小建议
- BGM: < 5MB per file
- SFX: < 200KB per file
- 总音频包: < 50MB

### 循环点设置
- BGM需在DAW中设置无缝循环
- 导出时确保循环点无爆音

## 🎛️ 七、混音建议

### 音量层级
```
Master: 0dB
├── BGM: -12dB to -18dB
├── Ambience: -20dB to -24dB
├── SFX: -6dB to -12dB
└── UI Sounds: -10dB to -15dB
```

### 动态范围
- BGM: 保持较窄动态范围，适合长时间播放
- SFX: 可以更有冲击力，短促有力
- 避免音频疲劳

### 频率分配
- BGM: 全频段，注意给SFX留出空间
- SFX: 根据类型分配频段
  - UI: 中高频 (2k-8k Hz)
  - 环境: 低频 (20-500 Hz)
  - 警报: 中频 (1k-4k Hz)

## 🎨 九、风格指南

### 整体音频美学
- **反乌托邦低保真**: 轻微失真、不完美感
- **数字与模拟混合**: 电子元素 + 真实录音
- **阶级听觉区分**:
  - 贫民窟: 嘈杂、混乱、高噪音
  - 铁锈带: 工业、机械、重复
  - 郊区: 过于干净、虚假、有"塑料感"
  - 核心区: 高科技、冷漠、精确

### 情绪参考
- **Insight低时**: 平淡、日常、 elevator music
- **Insight高时**: 故障、不安、超越感
- **危机时刻**: 心跳加速、环境音扭曲
- **觉醒时刻**: 静默、宇宙背景辐射般的嗡鸣
