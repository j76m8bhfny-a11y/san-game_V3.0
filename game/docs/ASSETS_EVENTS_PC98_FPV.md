# Event Assets Guide - PC-98 First-Person Eye-Level

> Version: 5.0 | Pure First-Person | 3:2 (960x640) | 250 Events

## 🎯 Prompt Structure

```
first-person view at [US location], eye-level perspective,
[event scene description],
[atmosphere mood],
diverse multi-ethnic Americans in scene,
no protagonist visible, no hands in frame, no self visible,
first-person POV looking at scene
```

## ✅ Key Features

- **First-person eye-level**: Standing and looking at the event
- **No protagonist visible**: No hands, no body, pure POV
- **Diverse Americans**: Multi-ethnic people in authentic US settings
- **American elements**: US locations, culture, environment
- **Looking AT the event**: The event is the focus
