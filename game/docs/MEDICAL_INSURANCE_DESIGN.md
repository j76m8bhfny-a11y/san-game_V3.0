## 一、治疗项目与Debuff治愈范围

### 1. 流浪汉阶级 (SLUMS)

| 治疗项目 | 类型 | 价格 | 治愈范围 | 效果 | 限制 |
|---------|------|------|---------|------|------|
| **CVS非处方感冒药** | DRUG | $18 | `FLU_LOW` (贫民窟流感) | HP+5, InsightClear+2 | 不治本，仅缓解症状 |
| **地下黑诊所缝合** | SURGERY | $150 | `FOOD_POISONING` (食物中毒) | HP+30, 感染风险Buff | 无麻醉，可能留下并发症 |
| **公立医院急诊室** | EMERGENCY | $3,500 | 所有`ACUTE`(急性病) | 治愈急性病 | HOMELESS白卡免费，但产生不可偿还的医疗债务记录 |
| **血浆捐献** | SPECIAL | -$40 | 无 | HP-15, MaxHP-2, +$40 | 每周限1次，身体透支 |

**治愈范围说明：**
- 只能处理最基础的轻症（流感、食物中毒）
- 急性重病（败血症、心脏病发作）必须依赖公立医院急诊，但会产生长期债务阴影

## 二、保险术语说明（生涩美国医疗术语）

### 1. 短效极简健康险 (Short-Term Junk Plan)

```
【计划摘要】
- 计划类型：Short-Term Limited Duration Insurance (STLDI)
- 符合《平价医疗法案》(ACA) 豁免条款，非全面医疗保障

【覆盖范围】
- 急诊室就诊 (Emergency Room Visit)：适用In-Network共付额
- 预防性服务：不适用 (依据ACA最低基本覆盖要求豁免)
- 既有疾病 (Pre-existing Conditions)：等待期12个月

【费用分担】
- 年度免赔额 (Deductible)：$7,500 (个人)
- 共付比例 (Coinsurance)：您支付40%，计划支付60%
- 年度自付上限 (Out-of-Pocket Maximum)：$20,000

【重要提示】
本计划不满足ACA的最低基本覆盖标准。您可能仍需支付联邦税费罚款。
本计划不保证续保，保险公司有权基于理赔历史拒绝续保申请。
```

---

### 2. 高免赔额企业医保 (HDHP - High Deductible Health Plan)

```
【计划摘要】
- 计划类型：HSA合格高免赔额健康计划
- 与健康储蓄账户 (Health Savings Account) 兼容

【覆盖范围】
- 网络内急诊 (In-Network Emergency)：免赔额满足后80%报销
- 网络外急诊 (Out-of-Network Emergency)：免赔额满足后50%报销
- 精神健康服务 (Mental Health)：不覆盖 (由雇主单独选购EAP)
- 成瘾治疗 (Substance Abuse)：不覆盖

【费用分担】
- 年度免赔额 (Deductible)：$7,000 (必须全额自付后保险才生效)
- 共付比例 (Coinsurance)：免赔额满足后您支付20%
- 年度自付上限 (Out-of-Pocket Maximum)：$8,000

【HSA账户优势】
您可将税前收入存入HSA账户，用于支付符合资格的医疗费用。
雇主匹配供款：年度$500。

【限制说明】
在达到$7,000免赔额之前，您需全额自付所有医疗费用。
这意味着大多数日常医疗支出无法获得保险报销。
```

---

### 3. PPO黄金医疗网络 (PPO Gold Plan)

```
【计划摘要】
- 计划类型：Preferred Provider Organization (PPO) 优选医疗机构组织
- 金属等级：Gold (黄金级)
- 保险承担平均80%医疗费用，您承担20%

【覆盖范围】
- 首选医疗服务机构 (PCP)：无需转诊，直接预约专科医生
- 急诊服务 (Emergency Services)：全球覆盖，24/7
- 精神健康与物质滥用 (Mental Health & Substance Abuse)：覆盖
  - 门诊治疗：$40共付额
  - 住院治疗：免赔额后20%共付
- 处方药 (Prescription Drugs)：覆盖Tier 1-3

【费用分担】
- 年度免赔额 (Deductible)：$1,500
- 门诊共付额 (Copayment)：$40 (专科$60)
- 住院共付 (Coinsurance)：免赔额后您支付10%
- 年度自付上限 (Out-of-Pocket Maximum)：$6,000

【网络外服务 (Out-of-Network)】
- 您可选择网络外医生，但需支付更高费用
- 网络外免赔额：$3,000 (单独计算)
- 网络外共付比例：您支付40%

【事先授权要求】
以下服务需事先获得保险公司授权，否则可能拒赔：
- 住院手术
- MRI、CT扫描
- 精神健康住院治疗
```

---

### 4. 顶级私人医疗礼宾协议 (Platinum Concierge Insurance)

```
【计划摘要】
- 计划类型：Executive Medical Concierge Program (EMCP)
- 保障等级：Platinum Plus
- 全球医疗网络覆盖，无限额度

【专属服务】
- 私人礼宾医生 (Personal Concierge Physician)：7×24小时直接联络
- 全球第二诊疗意见 (Global Second Opinion)：梅奥诊所、克利夫兰诊所优先通道
- 空中医疗转运 (Air Ambulance)：全球范围，直升机或医疗专机
- 器官移植协调 (Transplant Coordination)：UNOS等待列表优先排序

【覆盖范围】
- 所有医疗服务：100%报销，无免赔额
- 精神健康与成瘾治疗：全额覆盖，包括海外静修中心
- 实验性治疗 (Experimental Treatments)：FDA一期临床试验准入
- 抗衰老干预 (Anti-aging Interventions)：NAD+疗法、 Senolytics

【费用分担】
- 年度免赔额 (Deductible)：$0
- 共付额/共付比例：$0 / 0%
- 年度自付上限 (Out-of-Pocket Maximum)：无上限 (因无自付要求)
- 终身最高限额 (Lifetime Maximum)：无限制

【特权条款】
- 器官移植：提供"移植旅游"服务，包括海外器官获取
- 药物获取：FDA未批准药物通过Compassionate Use Program获取
- 隐私保护：医疗记录隔离存储，不进入常规保险数据库

【免责声明】
本计划涉及的部分服务（如海外器官获取、实验性治疗）可能违反部分司法管辖区法律。
保险公司提供协调服务，但不承担法律风险。客户需自行评估合规性。
```

## 四、关键机制说明

### 1. 治愈范围层级

```
治愈能力层级：

Level 1 (贫民/街头)：
  - 治愈：FLU_LOW, FOOD_POISONING
  - 控制：无
  - 无法处理：CHRONIC, ACUTE, MENTAL

Level 2 (蓝领/Urgent Care)：
  - 治愈：FLU_LOW, FOOD_POISONING, WORKER_LUNG(早期)
  - 控制：HYPERTENSION, TYPE_2_DIABETES
  - 无法处理：HEART_DISEASE, SEPSIS, MENTAL

Level 3 (中产/综合医院)：
  - 治愈：所有ACUTE, 大部分CHRONIC
  - 控制：所有疾病
  - 昂贵但有：MENTAL治疗

Level 4 (资本/VIP)：
  - 治愈：一切疾病包括器官衰竭
  - 特权：器官移植优先权
```

### 2. Insight方向与医疗的关联

| Insight状态 | 医疗行为影响 |
|-------------|-------------|
| 0-30 (蒙昧) | 容易接受任何治疗，不会质疑账单 |
| 30-70 (初觉) | 开始注意到医疗费用不合理，可能拒绝治疗 |
| 70-85 (觉醒) | 看清医疗系统的剥削本质，产生抗拒心理 |
| 85-100 (通透) | 完全看透，可能选择"不治疗"作为抗议，加速死亡 |

**设计意图**：高Insight玩家虽然"清醒"，但可能因看透太多而拒绝必要治疗，形成"聪明反被聪明误"的悲剧。
